# DiT V2.3: Flow Matching / Rectified Flow Evolution

## 📋 概述
DiT V2.3 是本项目的“终极”去噪范式升级，将原本基于随机微分方程（SDE）的 Diffusion 模型升级为基于常微分方程（ODE）的 **Flow Matching (流匹配)** 模型。

## 🛠️ 技术改进
- **Rectified Flow 路径**: 训练目标从拟合噪声 $\epsilon$ 变为拟合速度向量 $V_t$。采样路径从弯曲随机路径变为了从噪声到目标的**最短直线路径**。
- **ODE Euler Solver**: 推理采样不再使用调度器，而是通过一个 10 步的欧拉积分求解器直接推演轮廓位置。
- **连续时间 $t \in [0, 1]$**: 网络适配了连续的时间步输入，使去噪过程更加数学严谨。

## 📈 收益
- **推理速度飞跃**: 从 DDIM 的 50 步降至 **10 步** 即可达到同等甚至更高的质量（约 5 倍提速）。
- **训练收敛最快**: 拟合直线（常数向量场）比拟合随机噪声极大地降低了网络的优化难度，训练 Loss 下降更加丝滑。
