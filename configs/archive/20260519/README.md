# Archived Configs: 2026-05-19

These files were moved out of the root `configs/` directory to reduce clutter.
They are not deleted.

## Folders

- `ablations/`: completed or retired mechanism ablations.
- `rl/`: GRPO/RL trials.
- `sam_swin_yolo/`: SAM, SAMSnake, Swin, and YOLO detect-only trials.
- `retired_diffusion/`: older diffusion/FM experiments that are not active.
- `misc/`: heatmap and miscellaneous configs.

If an archived config needs to be resumed, either reference it by its archive path
or copy it back to `configs/`.
