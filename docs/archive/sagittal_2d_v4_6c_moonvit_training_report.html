📋 架构设计

核心决策：纯2D，不做伪3D

经过诊断分析，之前的 pseudo-3D step5000 效果差（GT-box foreground Dice 0.13）是因为训练/推理初始化不一致导致 Flow 系统性外扩。新方案回归纯2D单帧，保持和最早2D版本一致的输入，特征换用 MoonViT。

🔄 时序传播机制（已实现）

prev_contour_init_prob: 0.3

训练时以30%概率用相邻slice的GT轮廓作为当前实例的Snake初始化，替换标准octagon。关键设计：

  • 训练侧：优先读取 prev slice mask，提取同类别轮廓，应用相同空间变换（augmentation），重采样到与GT相同点数，起点对齐后作为 i_it_py
  • 推理侧（预留）：帧N处理后缓存预测轮廓，帧N+1按类别+bbox IoU匹配，复用前帧轮廓初始化（当前代码已预留接口，未实装）
  • Fallback：相邻帧无该类别时退回octagon
  • 无噪声：GT轮廓直接使用，不加随机扰动（简化设计）

意义：矢状位相邻切片解剖结构几乎一致，相邻轮廓离当前GT非常近（几像素偏移），Flow模型从"质量极高的初始化"学习小幅精修，契合 rich-state sampling 的 near_zero_state 分布，同时自然对齐训练/推理初始化来源。
