# V3.5 问题记录

## 现象

V3.5 单样本结果在正常推理路径下明显失真，轮廓和检测框大量偏离目标器官，表现为整图乱线、框漂移、轮廓叠加。

## 关键结论

这不是单纯的可视化问题，也不是傅里叶后处理本身造成的。

更准确地说，V3.5 当前的训练结果不能直接支撑“正常单样本预测”，因为它依赖的检测起点没有被真正训练好。

## 证据

1. 单样本测试里，GT 轮廓数是 6，但模型输出了 11 个检测框。
2. 检测分数里存在大量低置信度框，最低仍有 `0.011` 左右。
3. 训练日志里 `det_loss_scaled` 一直是 `0`，说明检测头没有参与训练。
4. 推理时却仍然要靠检测框生成初始轮廓，导致后面的扩散过程建立在错误起点上。

## 影响

- 正常单样本推理结果不可信。
- V3.5 当前不能和 V3.0/V3.4 直接放在同一条推理链上比较。
- 现阶段看到的乱图，主要反映的是“起点框错误 + 训练目标不完整”，不是傅里叶表示一定失败。

## 相关位置

- 配置：`configs/btcv_diffusion_dit_v3_5_single_overfit.yaml`
- 检测初始化：`lib/utils/snake/snake_gcn_utils.py`
- 推理分支：`lib/networks/diffusion/pretrain_evolution.py`
- 损失汇总：`lib/train/trainers/diffusion_trainer.py`

## 下一步建议

1. 先用 GT 起点单独验证 V3.5 的扩散部分。
2. 如果要做正常推理，必须先把检测头也纳入训练。
3. 在检测头未修复前，不建议继续把 V3.5 当成可直接使用的单样本结果。
