从演化到生成,从位移到轮廓
——几何桥流匹配新范式

把 Flow Matching 从「纯噪声 → 位移」重构为「初始轮廓 → GT 轮廓」的 data-to-data 直线桥,让演化 = 生成 = 位移三者合一,从结构上消解 V5 RL 的 0.860 天花板。

方向:扩散式医学图像分割数据:BTCV / 1232_final主线:V3.4-FM → 几何桥 → RL

0起点:0.860 这堵墙

整条研究线由一个未解的瓶颈驱动——V5 RL 后训练撞在 0.860 天花板,无论怎么调探索分布、reward、模态数,都推不动高频细节。

统一定论(见 worklog / memory v5_detail_reward_unsaturated):

天花板 = 低频 geom 动作空间的表达上限。根因是——模型空间 ≠ 动作空间:预训练 FM 在 latent / 位移空间很强,但 RL 后训练只能在它上面挂一层 8 模态低频 Fourier 法向动作;reward 推不动预训练表示里压根没有的高频细节。

于是问题被推回到根本:能否从根上让"预训练空间"与"RL 动作空间"本是同一个? 这就是新范式的动机。但要理解它为什么是这个形态,得先把五个「为什么」讲清楚——它们是一条因果链,不是并列。

1为什么是 DeepSnake

因为表示决定上限。DeepSnake 用显式闭合轮廓,Unet 用隐式像素场——这一差异决定了拓扑、语义、与"可迭代"三件事。

① 显式轮廓 vs 隐式像素场左侧全局上下文 · 右侧局部判别
DeepSnake · instance-aware · 拓扑闭合
Unet · 局部卷积 · 易断连/空心/多余

拓扑性

闭合曲线是 1D 流形,自相交受流形约束;像素 mask 的连通性是 2D 区域性质,局部误判即破坏全局连通。医学器官相邻、形状复杂(凹陷、分叶),拓扑错误(粘连/断裂/空心/中心多余)直接致命。师兄们论文多次提及。

语义层面

Snake 的 GCN message-passing 让每点聚合整条轮廓信息,是 instance-aware 全局上下文;Unet 卷积是 local 的,即便大感受野也是各向同性渐近,没有"这些像素属于同一器官实例"的归纳偏置。

第三个动机(为后文埋线): DeepSnake 是迭代式 refinement(可逐步纠错),Unet 是 one-shot。这个"可迭代"的特性,正是后面扩散 / FM / RL 能挂上来的接口——没有迭代演化,就没有"路径"可言。弱点(依赖好的初始轮廓)也被我们变成了下一篇的动机。

2为什么选择扩散生成

传统 Snake 是确定性位移回归,单一路径、与初值强绑定、易陷局部最优。扩散把演化建模成随机过程——生成式而非判别式。

② 扩散去噪 · 多样路径 · 逃离局部最优三条随机路径 vs 一条确定性路径
路径 A(随机) 路径 B(随机) 路径 C(随机) 确定性回归 → 局部最优 GT 轮廓

两条理由,把感性变成可论证

  • 路径多样性 / 逃离局部最优: 扩散沿 score 场的随机积分,采样路径带随机性 → 能逃离局部最优。判别式给点估计,生成式给分布,这是根本区别。
  • 不易过拟合(三条机理): ① score matching 学"把任意噪声拉回流形"的全局流形结构,逐点记忆难度高于坐标回归;② 多步去噪 = 隐式数据增强(每样本在不同 t、不同噪声下反复训练);③ score matching 的 loss landscape 比坐标回归更平滑,泛化更好。
但扩散有代价——推理慢(多步迭代)。 这正是后面引入 FM(直线插值→少步)的动机。扩散→慢→FM 直线化→少步→RL 多步,这条主线贯穿全篇。

3强化学习为什么重要

不是"数据更多",是转变优化目标:从模仿 GT 分布(代理损失 = velocity-MSE)转为最大化任务奖励(IoU / Dice,真实指标)。

③ RL · 优化目标转变 + 状态分布拓展rollout 分支探索偏离后的纠正
预训练直线路径 RL rollout(探索·纠偏) GT(真实指标) 拓展后的状态分布
  • 代理损失 vs 真实目标: MSE 低 ≠ IoU 高。Line B 卡 0.785 就是铁证——velocity-MSE 早饱和,但 rollout IoU 上不去。RL 直接对 IoU 优化,绕开这个 gap。
  • 拓展状态分布 = 治 exposure bias: 预训练只见 GT 路径上的状态;RL rollout 探索"偏离后如何纠正"的状态,等价 DAgger / 状态扩增,覆盖预训练见不到的分布。
  • 多样性路径: RL exploration 天然产生多样轨迹,与扩散的随机性叠加。
诚实点(也是新范式动机): RL 在连续高维动作空间(128×2)样本效率低、信用分配难、reward 稀疏——这正是撞 0.860 墙的原因。新范式要做的,就是给 RL 一个全分辨率、低频干净的几何动作空间,降低 RL 难度。把"RL 为什么难"讲出来,新范式价值才凸显。

4为什么 MoE

单一 MLP 不是"容量不够",是多模式回归的 mode 冲突——不同器官、不同局部需要不同映射,挤在一个 MLP 里互相干扰。MoE 条件计算分流。

④ MoE · 频域分工:共享专家 + 路由专家低频先验 ⊕ 高频细节
共享专家(低频平滑) → 叠加路由专家(高频局部) → 还原复杂轮廓
共享专家(低频先验) 路由专家1(高频) 路由专家2(高频) 总和 = 目标轮廓
  • 共享 + 专门: shared expert 学公共、低频的轮廓先验(大致形状),routed experts 学高频、器官特异的细节修正——对应 config moe_use_shared_expert:true + routed experts。
  • 工程扎实: 条件激活带来参数效率与可扩展性;router collapse 需 balance loss 约束(moe_balance_weight:0.001)。
张力点(引出新范式): MoE 给了容量,但 routed expert 的高频探索被毛刺(burr-prone)卡住——因为探索空间(动作空间)被预训练范式的低频表示锁死。MoE 也没能突破,这恰恰说明问题不在容量,在动作空间本身。→ 引出新范式。

5新训练范式与 FM 的关系

这是最核心、最有原创性的一条。三层递进:经验观察 → 直觉跃迁 → 表示转变,最终演化/生成/位移三者合一。

(a) 经验观察

基于位移训练时,中间插值越密效果越好——说明演化轨迹的质量(连续、光滑)决定效果,而非只看端点。

(b) 直觉跃迁

插值本质 = 线性路径;FM 的速度场目标在直线上是常数 v = x₁ - x₀,FM 天然"沿直线/近直线积分"——二者数学同构。这个直觉把研究从"位移回归"引向 FM。

(c) 关键转变(原创点)

从训练位移(Δx,显式预测目标)→ 训练轮廓坐标本身(x 作为 FM 的样本):

x₀ = 初始轮廓(init)   # FM 的起点 / 噪声态
x₁ = GT 轮廓        # FM 的终点 / 数据态
x_t = (1−t)·x₀ + t·x₁   # 直线 init→GT 桥
速度目标 v = x₁ − x₀     # 常数(直线常速度场)

(d) ODE 去噪 = 位移

每步去噪增量 Δx_t 就是该步位移——位移不再是显式预测目标,而是积分过程的自然产物。演化与生成不再割裂。

下面两个动画并排对照,看清范式的差别:
  • ⑤⁻ 老范式(上): FM 在位移空间去噪。x₀ = 纯噪声 ε(无几何意义的一团乱麻),x₁ = 位移 Δ。轮廓本身固定不动,去噪只是把挂 init 上的位移向量从噪声"清理"成真实位移。模型空间(位移)与轮廓演化是两套东西。
  • ⑤ 新范式(下): FM 在轮廓空间去噪。x₀ = init 轮廓,x₁ = GT 轮廓,x_t 是正在爬行的轮廓本身。去噪 = 演化 = 位移,三者同一空间。模型空间 = 动作空间,这正是消解 0.860 墙的结构性根因。
⑤⁻ 老范式 · 纯噪声 ε → 位移向量 ΔFM 起点是高斯噪声,终点才是位移;轮廓坐标固定不动
纯噪声 ε(x₀,无几何意义) 位移场 Δ(被预测的目标) 固定 init 轮廓(不演化) GT 轮廓(init+Δ)

init 轮廓(八边形,x₀) GT 轮廓(x₁) x_t 插值轮廓 位移向量 v=x₁−x₀

⑥ 位移空间:为什么是"直线" → 为什么能少步同一 velocity 在不同 t 完全一致
FM 直线路径(velocity 恒定) 纯扩散曲线路径(velocity 随 t 变) → 直线 = rectified flow,2-4 步即可;曲线需几十步
⑦ 推理:单桥 Euler 积分,轮廓逐步爬行对比:旧范式一次性大位移 vs 新范式多步小爬
K 步 Euler:每步 v·dt,轮廓从 init 爬向 GT
  • (e) 步数易控 + 推理成本骤降: FM 直线 → rectified flow,少步即可,解决纯扩散慢的问题。
  • (f) 三者合一: 扩散(多步慢)→ FM 直线化(少步)→ 训练轮廓坐标(去噪=位移)。演化 = 生成 = 位移。
  • (g) 与 RL 统一: RL 经验上多步探索更好;FM 少步 + RL 多步 rollout 在"轨迹质量"上同源;RL 路径多样性与扩散/FM 随机性一致,符合初心。

诚实定位(组会必讲)

高 IoU 不是预训练阶段的目标。新范式价值在:① 统一表示(演化=生成=位移),消除预训练空间与 RL 动作空间错位;② 给 RL 干净的全分辨率几何动作空间(128×2 per-point);③ 推理便宜(少步)。0.785 已破 init、远超 fixed-feature,作为"给 RL 的起点"合格。主动摊开讲边界,比被问到再解释强。
