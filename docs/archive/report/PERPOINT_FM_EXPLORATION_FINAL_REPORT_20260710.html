1. 问题与目标

低频 geom 探索只能用少量 Fourier 模式整体扰动轮廓。它适合低频形变，但难以表达局部凹陷、局部粘连、单个边界段偏移等精修动作。逐点路线的目标是：让策略针对每个轮廓点学习 FM velocity 的微小幅度调节，从而扩大局部探索空间。

真正困难不只是“动作维度变高”。逐点探索同时引入四个耦合问题：动作可能反向造成锯齿；不同 rollout 扰动不同空间区域导致不可比较；单点动作经过 mask 栅格化后 Reward 几乎为零；类别不平衡会让策略塌缩成所有点统一减速。

2. 全程保持的设计约束

约束实现目的
动作必须沿 FM velocity不是法线噪声，不改变方向基保持 FM 与 DeepSnake 的主体结构
不能反向scale=tanh(raw)×0.1multiplier 始终位于 (0.9, 1.1)
必须是真实五步 rollout后一步 state 包含前一步实际动作避免退化为单步 RL
归因必须局部共享选区 + pointwise log-prob + pointwise advantage杜绝跨区域和选区内部共享标量归因
Reward 必须有连续分辨率点到闭合 GT polyline 的连续距离避免单点微动作被像素栅格化吞掉
不使用额外熵正则entropy_weight=0保持实验边界清晰
不使用 burr 硬惩罚reward_burr_weight=0避免高噪声惩罚压制微弱局部信号

3. 最终方法：v15 末两步逐点 FM Scale

3.1 动作参数化

rawi ~ Normal(μi, σi)　→　scalei = tanh(rawi) × 0.1　→　actioni = FMi × (1 + scalei)
  • 每个点独立产生幅度调节，但动作方向仍由 FM velocity 决定。
  • 乘子严格限制为 (0.9, 1.1)，适合精修任务的小幅动作。
  • log-prob 使用 tanh change-of-variables 修正，PPO ratio 与实际采样分布一致。

3.2 五步时序窗口

Outer stepfraction执行动作探索进入 PPO
10.2deterministic FM否否
20.25deterministic FM否否
30.3333deterministic FM否否
40.5逐点 FM scale是是
51.0逐点 FM scale是是

这不是两步 rollout。五个 state 均真实执行，第四步 state 由前三步 deterministic FM 生成，第五步 state 还包含第四步的探索动作。

3.3 连续逐点归因

crediti = clamp((d(pure FM pointi, GT) − d(sampled pointi, GT)) / 8px, −1, 1)

正值表示 sampled action 让该点更接近 GT 闭合边界；每个点的 log-prob 只与自己的 credit 配对。

4. 版本演进与根因定位

v1：逐点加性 velocity 偏移

探索 std 与 LR 太小，KL≈0，策略几乎不更新。

v2：逐点乘法 scale

梯度打通，但无界高斯导致 multiplier 可能小于 0，出现反向动作和严重 burr。

v3：tanh 有界 FM scale

动作限制到 (0.9,1.1)，彻底禁止反向；成为后续统一动作基。

v7–v9：发现跨 rollout 空间归因错误

不同 rollout 扰动不同区域，却用同组标量 Reward 排序，动作与 Reward 不可比较。

v10：共享 8 点选区 + joint log-prob

mask 外梯度严格为零，但 8 点仍共享 contour scalar credit，局部方向接近随机。

v11：真正 point marginal，暴露栅格量化

逐点归因正确，但 point credit std 仅 5e−6～9e−5，经常低于 1e−4 floor。

v12：连续边界距离 credit

信号放大约 45 倍、几乎全非零；策略却塌缩为所有点减速。

v13：零均值 local residual

消除统一减速塌缩，正负 recall 恢复平衡，但整体 balanced accuracy 仍约 0.5。

v14：100× policy LR 探针

更新幅度和 gain 放大，但局部方向准确率没有改善，说明瓶颈不只是 LR。

v15：完整五步，仅末两步探索与更新

最终步获得可重复局部信号；整体性能仍未超过基线。

9. 为什么局部信号没有转化为整体收益

  1. 第五步可学，第四步仍错误。两步联合策略中，第4步 balanced 低于随机，会污染第5步 state，并抵消最终步的正信号。
  2. 连续 credit 优化的是点到 GT 边界距离。它天然更贴近 NSD，因此 NSD 提升而 IoU / Dice / mBoundF 不同步提升并不矛盾。
  3. 零均值 local residual 禁止整体增减速。它修复了单类塌缩，但也限制了策略表达；如果某条轮廓大部分点都需要同向微调，零均值会强制相对补偿。
  4. 探索只覆盖一个连续 8 点组。空间归因因此干净，但每个训练 batch 的局部覆盖率有限，样本效率仍低。
  5. 策略网络能产生非零更新，但局部视觉特征与“应该加速还是减速”的对应关系仍弱。100× LR 只放大参数变化，没有提升方向准确率，排除了“单纯 LR 太小”。
  6. 逐点 Reward 与最终任务指标存在错位。连续距离是优秀的归因尺子，却不等价于最终区域质量函数。
关键区分：“逐点 credit 可分辨”“策略有局部信号”“最终指标优于基线”是三个不同层级。当前已完成前两个层级的一部分，但第三层级没有成立。

10. 最终结论与路线建议

问题结论
动作参数化是否合理？已解决 tanh 有界 FM scale 不反向，适合精修幅度。
是否还有跨区域错误归因？已解决共享选区、pointwise credit、mask 外零梯度。
单点 Reward 是否有足够分辨率？已解决连续边界距离将信号提升约 45 倍。
策略是否完全塌缩？已解决零均值 local residual 消除统一减速单类塌缩。
是否有局部学习信号？部分成立最终步 balanced=0.5396；第4步仍低于随机。
是否优于 deterministic FM？否只在 NSD 上显著提高，IoU / Dice / mBoundF 未提高。
是否优于 delta-NSD？否四项指标均显著更差。

建议的项目决策

  • 正式强化学习结果与论文主结果：继续使用 delta-NSD。
  • 逐点路线：保留 v15 checkpoint、配置和诊断，作为“局部探索机制研究”与后续方法储备。
  • 不建议：继续无界增加 LR、加大随机幅度、恢复反向动作、回到 raster point Reward。
  • 若以后继续：优先研究“只训练最终一步”的严格受控实验，以及让归因 Reward 与最终 NSD / boundary metric 更直接对齐；新增前需明确确认。
