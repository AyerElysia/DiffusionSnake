2D Flow Matching 改造与曲线推理路径完整工作报告

日期：2026-06-26  |  上下文：V4.6c 位移流 → 2D FM s-conditioning 改造 → 曲线推理

一句话总结：把位移流的隐式两维（去噪 t + 修正 s）变成显式二维条件输入，让 FM 在 (s,t) 平面上学习一个统一的速度场。训练时 (s,t) 二维独立随机采样，覆盖整个平面。推理时可走任意路径——阶梯（当前）、对角线、下凸曲线。已实现曲线推理代码，但因 s_emb_net 需要充分训练才能生效，当前 100ep 的 checkpoint 还无法验证曲线效果。已在 1232_final 数据集上启动 10000ep 训练。

1. 改造的核心思想

1.1 原始位移流的隐式二维

V4.6c 的 rich-state sampling 实际上已经在两维上训练：

  • t 轴（去噪）：t ~ U[0,1]，标准 FM 从噪声到位移的线性插值
  • s 轴（修正）：frac ~ rich_state_sampling，从 init 到 GT 的修正进度

但模型只收到 t 和 x_t，必须从 x_t 的幅度隐式猜测 s。这导致：

  • 模型无法区分"去噪到 s=0.3 的位移"和"去噪到 s=0.7 的残差位移"——它们可能 x_t 幅度一样
  • MoE router 无法按修正阶段选择不同策略
  • 推理时只能用阶梯路径（固定 s → 从头去噪 → 推进 s）

1.2 显式二维后的状态空间

d    = GT - init  (完整位移)
s    = frac ∈ [0,1]  (修正进度)
x₁   = (1-s)·d       (残差位移)
x₀   = ε ~ N(0,σ²)   (随机噪声)
x_t  = (1-t)·ε + t·x₁ = (1-t)·ε + t·(1-s)·d

v_target = x₁ - x₀ = (1-s)·d - ε
模型学习: v_θ(x, s, t, feat) ≈ (1-s)·d - ε

训练时 (s, t) 二维独立随机：t ~ U[0,1]，s 通过 rich-state sampling 的 5 种分布混合（continuous 15% / discrete 40% / small 25% / hard-far 5% / near-zero 15%）。本次设计确保 s 和 t 独立随机采样，覆盖整个 (s,t) 平面。

1.3 物理意义

在任意 (s,t) 点：

contour(s,t) = init + (1-t)·ε + t·(1-s)·d
            = (1-t)·(init+ε) + t·(init+(1-s)·d)

contour_noisy      = init + ε          (带噪初始轮廓)
contour_partial_GT = init + (1-s)·d    (部分走向 GT 的轮廓)

每一步 contour 都是真实轮廓的线性插值——始终几何合法，feature resampling 有物理意义。

2. 实现细节

2.1 Denoiser 改动（dit_denoiser_v4_1.py）

  • 新增 use_s_conditioning: bool = False 参数
  • 新增 s_emb_net，结构完全同 time_emb_net（SinusoidalTimeEmbedding → Linear → SiLU → Linear）
  • Zero-init：s_emb_net 最后一层 Linear 的 weight 和 bias 全为 0 → warm-start 时行为和原模型完全一致
  • forward 新增 s 参数，cond_emb = t_emb + s_emb，替换所有 t_emb 使用位置（dit_layers、latent_loop、final_layer、per_point_delta_head）
  • 完全向后兼容：use_s_conditioning=False 时行为和原 V4.6c 100% 一致

2.2 Flow Matching Evolution 改动（flow_matching_evolution.py）

  • 新增 flow_2d_s_conditioning config 开关
  • predict_velocity 新增 s 参数，透传到 denoiser
  • 训练路径：s = 1 - ||x1_raw|| / ||full_disp||（精确等于 frac 因为 x1_raw = full_disp * (1-frac)）
  • 推理路径：所有推理方法（step_with_logprob、sample_with_logprob、_sample_disp_from_sampled_feat、_sample_disp_geom_bridge、sample_disp_iterative）统一透传 s
  • iterative 推理：累积 s = s + (1-s) * frac，每步传给模型

2.3 Feature Resampling 解耦

原代码 resample 被 geom_bridge 门控（必须 x0=0 才能 resample）。改造后解耦：

  • 训练：flow_resample_feat_at_xt 独立生效，沿 contour = init + denormalize(x_t) 重采 feature
  • 推理 inner ODE：_sample_disp_from_sampled_feat 循环内每步按当前 x_t 重采 feature（DeepSnake 式）
  • Heun corrector 步也在预测点重采 feature
  • 抗噪声训练：训练时 x_t 带噪，contour 带噪但合法，模型学会从带噪轮廓 feature 提取信号

2.4 曲线推理路径（sample_disp_curve）

在 (s,t) 平面上走幂函数曲线：

t(τ) = τ^(1/α)    (α > 1 → t 先快走 = 下凸)
s(τ) = τ^α        (α > 1 → s 后快走)

每步用 delta-based Euler 积分：

  • t 方向速度 = v_θ（模型预测）
  • s 方向速度 = -d̂（解析 = x1_hat / (1-s)）
  • dx = v_t * Δt + (-d̂) * Δs
  • 最终 disp = denormalize(d̂)

Feature resampling 跟随演化 contour。配 5 个 config 项：use_curve_inference、curve_alpha、curve_steps、curve_s_max、curve_resample_feat。

3. 实验结果

3.1 BTCV 上的初步验证（100ep checkpoint）

用 BTCV V4.6c newdist-long checkpoint warm-start，训练 s_cond 100ep 后的 eval：

配置IoU(5样本)说明
阶梯 5×20（baseline）0.904同一 checkpoint，不使用曲线
曲线 α=2, steps=20, resample on0.17s_emb_net 未充分训练
纯 t 方向（α=100, s 几乎不动）disp norm 爆炸d̂ = x1_hat/(1-s) 在 s→0.97 时放大 33×
根因分析：曲线推理依赖 d̂ = x1_hat / (1-s)，在 s→1 时数值放大噪声。这需要 s_emb_net 学好——让模型在不同 s 下输出不同的、可靠的 v_θ。100ep 训练远不够（s_emb_net 仍接近 zero-init），模型实际上无法区分不同 s 值。这是一个训练量问题，不是方法问题。

3.2 数据确认：训练时 s 和 t 是否二维随机？

确认：是。

  • t ~ U[0,1]，由 sample_train_t() 采样
  • s 通过 rich-state sampling 的 frac 随机采样（5 种分布混合）
  • 两者独立随机，覆盖整个 (s,t) 平面
  • 但 2D 训练难度远大于 1D：模型需要学习整个平面上的速度场，而非一条直线上的。这是为什需要 10000ep 训练。

  1. 等 1232_final 训练到 ~1000ep（约 1.5 天后）：第一个 checkpoint（ep200）出来即可初步评估，看 s_emb_net 是否开始有效
  2. 阶梯推理对比：同一 checkpoint 上比较阶梯 vs 曲线（α=2/1/0.5），看 s_cond 是否带来了阶梯推理的提升
  3. 曲线扫参：α ∈ {0.5, 1, 2, 3}，steps ∈ {10, 20, 40}，找最优曲线
  4. 上凸验证理论：α=0.5（上凸，s 先走 t 后走）应该在 d̂ 不准时导致更差结果，验证"下凸抑制 s 方向误差"的理论预测
  5. resample 口否：对比固定特征 vs resample 对最终 IoU 的影响

7. 关键风险

风险 1：训练时间过长
10000ep × 66 steps × ~2s/step ≈ 16 天/实验。两个实验并行需 16 天。可考虑增加 GPU 并行加速。
风险 2：2D 训练难度大，s_emb_net 可能学不好
2D 平面远大于 1D 直线，模型可能需要更多 epoch 才能让 s_emb_net 有效。如果 1000ep 还没效果，可能需要调 lr 或增加 s_emb_net 容量。
风险 3：曲线推理中 d̂ 的数值稳定性
d̂ = x1_hat / (1-s) 在 s→1 时放大噪声。解法：s_max=0.97 截断 + 最后一步直接用 x1_hat 不除 (1-s)。但需要 t 足够高时 d̂ 才可靠。
