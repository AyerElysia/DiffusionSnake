日期：2026-07-31

> 本文是 MoE 专项技术记录。演化失败的数据工程根因、关键 MoE 消融、主线修复与当前训练状态的完整叙事，见 `docs/report/MEMFLOWDIT_RECENT_WORK_REPORT_20260731.md`。

## 一、结论先行

本轮不沿用项目中旧的 DeepSeek-MoE 风格 DiT 路由器，而是从 2026 年新工作重新设计并完成可运行试验。

当前建议候选为：

- 只将 6 层 DiT 中第 1、3、5 层的 FFN 替换为 MoE；
- 4 个 SwiGLU 专家；
- Top-1，即每个轮廓只激活 1 个专家，激活比例 25%；
- 以整条轮廓为路由单位；
- 使用余弦原型路由、首批真实数据原型初始化、population-level φ-balancing 和轻量 routing contrastive loss；
- 不保留 shared FFN、点序号嵌入、循环卷积路由、router noise、法向/曲率细节分支等冗余结构；
- dense FFN 仅在加载旧 checkpoint 时被一次性复制到专家，MoE 模型中不再保留未使用的 dense FFN。

50-step 同条件试验中，4 专家 Top-1 的体积 Dice 为 **0.790186**，无 DiT-MoE 对照为 **0.788544**；8 专家 Top-1 为 **0.790228**，二者差异只有 0.000042。8 专家 Top-2 没有带来收益。因此，当前证据支持选择更简单的 4 专家 Top-1，但 50 step、单个验证体积只能说明“没有破坏且有短程正信号”，不能当作最终性能结论。

输出头的旧 hard-load 惩罚不向路由器传递梯度，已用最小 hard-φ 校正修复。100-step 隔离试验把输出头训练期 hard CV 从 0.9139 降到 0.5698；三体积固定 seed 的 GT/memory-off 体积 Dice 为 0.788267 → 0.788280，主指标持平。与 E4K1 DiT-MoE 联合后，50-step 固定 seed Dice 为 0.788461 → 0.788794。因而两项机制可以进入同一个 v0.6 主线候选，但仍不能把短程烟测当成最终性能定论。

## 三、2026 年论文调研与取舍

### 3.1 直接采用的思想

1. [$\phi$-Balancing for Mixture-of-Experts Training](https://arxiv.org/abs/2605.15403)，ICML 2026

   旧式 auxiliary balance loss 常依赖当前 mini-batch 的统计，批次小或样本相关性强时噪声很大。该工作直接优化总体路由分布，使用 soft routing probability 的 EMA 表示 population state，再通过凸势函数产生路由价格。本实现使用其 negative-Shannon-entropy φ 形式。

2. [Routing Matters in MoE: Scaling Diffusion Transformers with Explicit Routing Guidance](https://arxiv.org/abs/2510.24711)，ICLR 2026 / ProMoE

   这篇工作与本任务最直接相关：视觉 token 高度相关，普通线性 Top-K router 容易形成专家同质化或伪均衡。其原型路由、余弦相似度和 routing contrastive guidance 被本轮吸收。考虑到轮廓的 128 个点比普通图像 patch 更相关，本实现进一步把路由单位从“单点 token”改为“整条轮廓”。

3. [Three Phases of Expert Routing: How Load Balance Evolves During Mixture-of-Experts Training](https://arxiv.org/abs/2604.04230)，2026

   该工作指出 MoE 训练会经历早期均衡、稳定专门化、后期适度放松三个阶段。因此本项目不把“越均匀越好”当作最终目标，路由均衡仅用于防止早期死亡；最终判断仍由分割质量决定。

### 3.2 暂不采用的路线

1. [Routing-Free Mixture-of-Experts](https://arxiv.org/abs/2604.00801)

   它取消集中 router、softmax 和 Top-K，理论上很有吸引力，但目前更偏 LLM 场景，激活密度会动态变化。对于本项目当前需要严格控制显存、活跃计算量和可解释对照的阶段，风险大于收益。

2. 更复杂的专家剪枝、协方差/共现建模与动态容量设计

   这些方法增加了矩阵统计、调度或训练阶段机制。当前任务只有 6 个 DiT block，且第一目标是确认 MoE 是否真正有益，不应先引入难以归因的复杂度。

## 四、旧 MoE 的实际问题

对正式训练 step 100 做了 1 个完整验证体积、GT box、memory-off 的路由统计，共记录 **9,139,200** 次输出头路由决策。

旧输出头 MoE 的统计为：

- soft normalized entropy：0.97934
- Top-2 hard-load CV：0.95119
- Top-1 负载：
  - 专家 0：0.72%
  - 专家 1：0.74%
  - 专家 2：62.89%
  - 专家 3：4.03%
  - 专家 4：1.61%
  - 专家 5：26.05%
  - 专家 6：1.88%
  - 专家 7：2.09%

也就是说，soft entropy 看上去接近均衡，但真正的 Top-1 决策有约 **88.94%** 集中在两个专家上。旧监控会把这种状态误判为健康。

本轮因此同时记录：

- soft load；
- hard Top-K load；
- Top-1 load；
- hard-load CV；
- 低于 1% 的死专家数量；
- 每层调用数和路由 token 数。

结论：以后不能只看 soft entropy；必须把 hard Top-1/Top-K 分布作为 MoE 健康指标。

## 五、新 DiT FFN-MoE 设计

### 5.1 最小结构

每个被替换的 DiT block 使用：

1. 对当前轮廓的点 token 做均值池化；
2. LayerNorm 去除所有轮廓共有的强通道方向；
3. 与 4 个可学习 prototype 做余弦相似度；
4. Top-1 选择一个专家；
5. 所有轮廓点共享该语义路由；
6. 由一个 hidden dim 704 的 SwiGLU 专家替换原 dense SwiGLU FFN。

选择第 1、3、5 层交错替换，原因是：

- 保留一半 dense block 作为稳定路径；
- 避免 6 层全部稀疏化造成不必要的路由叠加；
- 与视觉 DiT-MoE 中交错设置的经验相符；
- 结构只有一个清晰变量：局部上下文层是否需要专家化。

### 5.2 数据感知 prototype 初始化

随机 prototype 在本任务中失败。轮廓描述向量共享方向太强，即使 soft probability 接近均匀，极小的 logit 偏移也会让一个专家赢得绝大多数 hard Top-K。

当前初始化只执行一次：

1. 从首批真实轮廓描述子中做 farthest-point seeding；
2. 做 4 次 spherical k-means 更新；
3. 将得到的中心写入可学习 prototype；
4. 后续推理无额外初始化开销。

### 5.3 φ-balancing

维护 soft routing probability 的总体 EMA：

`m <- decay * m + (1 - decay) * batch_mean_probability`

以 negative Shannon entropy 势函数得到 detached price，再作用于当前 soft probability。它针对总体分布而不是单个小 batch 的 hard count，且在分布均衡时梯度自然接近零，不需要额外的强制均匀机制。

### 5.4 checkpoint 继承与冗余删除

为了让试验从已验证的 dense DiT 起点开始：

- 加载旧 checkpoint 时，把对应 dense SwiGLU 的 `w1/v/w2` 一次性复制到每个专家；
- Top-1 与 Top-2 在初始化时都与原 dense FFN 数值等价；
- 完成复制后，MoE block 内不保留 dense FFN；
- 已通过 Top-1、Top-2 两个合成数值一致性测试。

删除 inactive dense FFN 后，4 专家候选的 base 参数由 18.31M 降至 **16.69M**，减少 1.62M 无效参数。

## 六、失败试验与定位过程

### 6.1 单点 token + 随机 prototype：失败

第 10 step：

| 设置 | soft entropy | hard CV | 最多死亡专家数 |
|---|---:|---:|---:|
| E4 K1 | 0.9823 | 1.4071 | 3 |
| E8 K1 | 0.9839 | 1.3727 | 4 |
| E8 K2 | 0.9839 | 1.0647 | 3 |

原因不是专家数不够，而是把 128 个高度相关的点误当作独立语义 token，同时随机 prototype 在共同方向上形成了稳定偏置。

### 6.2 整轮廓路由 + 随机 prototype：仍失败

改为整条轮廓路由后，随机 prototype 仍使第 3 层约 99.98% 的路由落到同一专家。说明只改变路由粒度不够，prototype 初始化本身也是关键。

### 6.3 整轮廓路由 + 真实数据 prototype：修复

E4 K1 在训练第 50 step：

- 平均 soft entropy：0.9991
- 平均 hard CV：0.3504
- 三层死亡专家数：0

这说明“整轮廓语义路由 + 数据感知 prototype 初始化”才是本轮真正解决退化的组合。

## 九、专家数与激活比的决策

### 9.1 为什么选 4 专家

- E4 K1 与 E8 K1 的体积 Dice 只差 0.000042，远小于当前试验的不确定性；
- E4 K1 的前景切片 Dice 比 E8 K1 高 0.00318；
- 删除 inactive dense FFN 后，E4 的 base 参数为 16.69M，E8 约为 23.18M；
- 当前训练量不足以让 8 个专家形成可靠且可复现的细分语义；
- 4 专家更符合本项目“先证明专家化有效，再扩容”的原则。

### 9.2 为什么选 Top-1

- E8 Top-2 比 Top-1 多激活一倍专家计算；
- E8 K2 的体积 Dice 只比对照高 0.00004；
- E8 K2 的前景切片 Dice 比对照低 0.00250；
- Top-2 的均衡改善没有转化为分割改善。

因此当前激活比例选 **1/4 = 25%**，不选 2/8。两者表面激活比例相同，但 E4 K1 的总容量更紧凑、单专家获得的数据更多、专家更容易在当前数据规模下学实。

## 十二、输出头 MoE 的类别专门化检验与最小修复

### 12.1 “类别不均衡造成专家各司其类”假设

该假设在机制上合理：如果不同输出专家分别擅长不同椎体类别，那么类别频率不均衡确实可能自然形成不均匀路由，不能只凭总体负载不均就判断退化。

为此，对正式训练 step 400 做了 GT box、memory-off 的条件路由诊断。诊断按类别、扩散时间、轮廓尺度和轮廓点位分别统计 Top-1，并记录 10,200 个前向事件、71,400 条轮廓事件，类别与路由事件匹配错误为 0。

全训练集统计确认数据本身确实不均衡：80 个病例、14,384 张切片中，单类前景像素量最大约为最小的 25.8 倍，单类出现切片数最大约为最小的 24.9 倍，病例覆盖数从 3 到 64 不等。因此用户提出的前提成立；需要检验的是路由是否真的把这种不均衡转化成有意义的类别专门化。

结果不支持该假设解释当前塌缩：

- 全局 Top-1 负载为 `[0.0090, 0.0096, 0.6240, 0.0447, 0.0219, 0.2475, 0.0206, 0.0227]`；
- 已观察的 5 个类别中，专家 2 均约占 62%，专家 5 均约占 25%，没有类别间的专家换挡；
- 类别均衡反事实负载与原始负载的 L1 距离只有 `0.000116`；
- 归一化互信息：类别—专家 `0.000087`、时间—专家 `0.014106`、尺度—专家 `0.007215`、点位—专家 `0.000577`。

因此，当前专家集中不是已观测类别不均衡产生的有效类别专门化。时间和尺度有少量相关性，但不足以解释专家 2 与专家 5 合计承担 87% Top-1 决策的现象。

结构检查也与此一致：当前输出路由器只接收轮廓 token、点位嵌入、扩散时间和循环混合特征，没有显式类别 embedding。它可以从视觉和几何上下文间接推断类别，但网络并未提供一个足以证明“按类别各司其职”的直接条件。

### 12.2 旧平衡损失的直接缺陷

旧输出头损失同时计算 soft importance 与 hard Top-K load，但 hard load 来自离散 `scatter` 计数，不对路由 logits 传递梯度。也就是说，日志里虽然存在 hard-load 惩罚值，优化器实际只能优化 soft importance。

这解释了同时出现的两个表面矛盾：

- soft entropy 仍高达约 0.98；
- hard Top-1 却长期集中到少数专家。

### 12.3 最小 hard-φ 修复

保留现有 8 个输出专家、Top-2、共享基线头和全部 checkpoint 参数，只替换负载校正：

1. 用真实 hard Top-K 选择更新专家负载 EMA；
2. 把 EMA 转换为不反传的拥塞价格；
3. 用当前 soft probability 承载梯度，使过载专家 logits 收到明确的下降梯度；
4. 默认配置仍为 `legacy`，只有隔离实验显式启用 `hard_phi`。

没有加入类别路由、法向细节采样、新输出专家结构或多阶段调度。单元测试已验证：在两个专家被硬路由过载时，新损失对过载专家产生正 logits 梯度、对闲置专家产生负 logits 梯度；梯度下降方向与去退化目标一致。
