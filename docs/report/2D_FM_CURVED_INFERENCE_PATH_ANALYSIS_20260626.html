2D Flow Matching 曲线推理路径理论分析

日期：2026-06-26  |  上下文：V4.6c 位移流 + 2D s-conditioning 改造

结论先行：在 2D FM (s, t) 面上走一条下凸曲线（t 轴先快走、s 轴后快走）在理论上可行且 well-posed。它消除了阶梯路径（当前 iterative refinement）每步从噪声重新去噪的浪费，同时保持每步 contour 的物理意义和 feature resampling 的有效性。主要风险是 s 方向速度依赖 d̂（位移估计），误差会沿曲线累积——但下凸曲线的设计让 t 先到高位，使 d̂ 在 s 开始快走时已经足够准，从结构上抑制了这个风险。

1. 2D FM 面的完整定义

1.1 训练时的状态空间

2D 改造后，训练在 (s, t) 二维空间上采样：

d    = GT_displacement  (init → GT 的完整位移)
s    = frac ∈ [0, 1]    (refinement 进度：0=init, 1=GT)
x₁   = (1 - s) · d       (残差位移：还没走完的部分)
x₀   = ε ~ N(0, σ²I)    (随机噪声)
x_t  = (1 - t) · x₀ + t · x₁ = (1-t)·ε + t·(1-s)·d

v_target = x₁ - x₀ = (1-s)·d - ε

模型学习：v_θ(x_t, s, t, feat) ≈ (1-s)·d - ε

1.2 任意 (s, t) 点的 contour 物理意义

contour(s, t) = init + denormalize(x_t)
             = init + (1-t)·ε + t·(1-s)·d
             = (1-t)·(init + ε) + t·(init + (1-s)·d)
             = (1-t)·contour_noisy  +  t·contour_partial_GT

每一步 contour(s,t) 都是 contour_noisy（带噪初始轮廓）和 contour_partial_GT（部分走向 GT 的轮廓）的线性插值——始终是真实轮廓（带噪但几何合法），feature resampling 有物理意义。

1.3 模型在任意点的恢复能力

给定 (s, t) 和 x_t，模型预测 v_θ，恢复 x̂₁：

x̂₁ = x_t + (1 - t) · v_θ
   = (1-t)·ε + t·(1-s)·d + (1-t)·[(1-s)·d - ε]
   = (1-s)·d  = x₁   (精确解)

因此 在任意 (s,t) 点，模型都能恢复 x₁ = (1-s)·d，进而得到 d̂ = x̂₁ / (1-s)（当 s < 1）。这是曲线推理的数学基础。

2. 当前阶梯路径 vs 提议的曲线路径

2.1 阶梯路径（当前 iterative refinement）

for each outer step i:
    s_i 固定
    t: 0 → 1  (完整去噪，从新噪声开始)
    d̂_i = denormalize(x̂₁)
    contour += frac_i · d̂_i
    s_{i+1} = s_i + (1 - s_i) · frac_i

问题：每个 outer step 从 t=0（纯噪声）开始去噪。模型每次都要从噪声重新发现位移 d。N 步 refinement = N 次从头去噪 = N × M 次速度评估。

2.2 下凸曲线路径（提议）

τ ∈ [0, 1]  (单一参数)
t(τ) = τ^(1/α)     (α > 1 → t 先快走)
s(τ) = τ^α          (α > 1 → s 后快走)

每步：
    contour = init + denormalize(x)         ← 真实（带噪）轮廓
    feat = resample(contour)                ← DeepSnake 式重采
    v = v_θ(x, s(τ), t(τ), feat)            ← t 方向速度
    d̂ = (x + (1-t)·v) / (1 - s)            ← 位移估计
    dx = v · dt/dτ + (-t · d̂) · ds/dτ      ← 二维速度合成
    x = x + dx · dτ

优势：去噪只做一次（累积的），不从头重来。K 步 ODE = K 次速度评估，远少于 N × M。

3. 曲线路径的严格数学分析

3.1 沿曲线的全微分

曲线 (s(τ), t(τ)) 上，状态 x(τ) = (1-t(τ))·ε + t(τ)·(1-s(τ))·d 的全微分：

dx/dτ = ∂x/∂t · dt/dτ + ∂x/∂s · ds/dτ

∂x/∂t = (1-s)·d - ε    ← t 方向速度（模型学的）
∂x/∂s = -t·d            ← s 方向速度（解析的，但依赖 d）

dx/dτ = v_θ(x, s, t) · dt/dτ + (-t · d) · ds/dτ

3.2 s 方向速度的推理时处理

推理时 d 未知，用模型估计 d̂：

x̂₁ = x + (1 - t) · v_θ(x, s, t, feat)
d̂  = x̂₁ / (1 - s)        (当 s < 1)

s 方向速度 = -t(τ) · d̂ · ds/dτ
关键观察：d̂ 的精度取决于 t 的高低。t 越接近 1，x̂₁ 越接近真实 x₁，d̂ 越准。下凸曲线的设计让 t 先到高位（如 τ=0.3 时 t≈0.8），此时 d̂ 已经较准，之后 s 快走时 d̂ 可靠。这正是下凸优于对角线或上凸的原因。

3.3 Well-posedness（适定性）

曲线 ODE dx/dτ = f(τ, x) 的适定性要求 f 满足 Lipschitz 条件：

  • v_θ 是神经网络，近似 Lipschitz（参数有界 + LayerNorm）
  • d̂ = (x + (1-t)·v_θ) / (1-s)，当 1-s 有正下界时 Lipschitz
  • t(τ), s(τ) 是光滑确定性函数

结论：只要 s(τ) < 1 - δ（直到 τ→1 才到 s=1），ODE well-posed。

3.4 误差分析

设 v_θ 的预测误差为 e_v（即 v_θ = v_true + e_v），则：

d̂ = d + (1-t)·e_v / (1-s)

s 方向速度误差 = -t · [(1-t)·e_v / (1-s)] · ds/dτ

误差量级 ∝ t·(1-t) / (1-s) · |e_v| · |ds/dτ|

当 t → 1 时，(1-t) → 0，s 方向误差趋零。下凸曲线在 s 快走阶段 t 已接近 1，所以：

误差 ∝ (1-t) → 0    (s 快走时 t ≈ 1，误差被抑制)

这是下凸曲线最核心的理论优势：结构性地将 s 方向误差积累放在 t≈1 的低误差区间。

3.5 与阶梯路径的误差对比

性质阶梯路径下凸曲线路径
每步去噪起点t=0（纯噪声）累积，不重置
每步 d̂ 精度依赖完整去噪 M 步依赖当前 t（高位时很准）
误差跨步关系独立（每步从新噪声开始）累积但有 t≈1 抑制
速度评估次数N × MK（K ≪ N×M）
feature 轨迹离散跳变连续平滑
训练分布覆盖每步 (s_i, t∈[0,1])曲线上 (s(τ), t(τ))，训练均匀覆盖全平面

4. 曲线参数化

4.1 幂函数曲线族

t(τ) = τ^(1/α)
s(τ) = τ^α
α形状τ=0.3 时 (s, t)τ=0.7 时 (s, t)特点
1对角线(0.30, 0.30)(0.70, 0.70)对称，无偏好
2下凸(0.09, 0.55)(0.49, 0.84)先去噪后refine
3更强下凸(0.03, 0.67)(0.34, 0.89)更早完成去噪
∞极限(0, 1)(0, 1)→(1,1)退化为阶梯（先全去噪再全refine）
α→∞ 的极限就是阶梯路径（先 t:0→1 再 s:0→1）。α=1 是对角线。α∈[2,4] 是"先快速去噪到 t≈0.8，再渐进 refine"的甜区。

4.2 更灵活的参数化：贝塞尔曲线

用二次贝塞尔曲线控制曲率：

P₀ = (0, 0),  P₂ = (1, 1),  P₁ = (β, 1-β)   控制点
(s(τ), t(τ)) = (1-τ)²·P₀ + 2(1-τ)τ·P₁ + τ²·P₂

β < 0.5 → 下凸（t 先走）  |  β > 0.5 → 上凸（s 先走）

5. Feature resampling 沿曲线的分析

沿曲线 (s(τ), t(τ))，contour 演化为：

contour(τ) = init + (1-t(τ))·ε + t(τ)·(1-s(τ))·d
τ(s, t)contour 组成feature 质量
0.0(0, 0)init + ε（纯噪轮廓）差（但 s_emb=0，模型知道在起点）
0.2(0.04, 0.45)init + 0.55ε + 0.43d中等（位移信号已占主导）
0.5(0.25, 0.71)init + 0.29ε + 0.53d好（噪声弱，位移清晰）
0.8(0.64, 0.89)init + 0.11ε + 0.32d很好（几乎纯位移轮廓）
1.0(1, 1)init + d = GT完美

关键：α=2 时，τ=0.5 已经 71% 去噪，contour 以位移为主。feature resampling 从 τ≈0.4 开始就高度有效。而阶梯路径每个 step 都从 t=0（纯噪 contour）开始，feature 在前几步 inner ODE 几乎无用。

6. 风险与缓解

风险 1：s 方向误差累积
s 方向速度用 d̂，d̂ 有误差 → 误差沿 τ 积分。
缓解：下凸曲线让 t 先到高位 → d̂ 在 s 快走时已准 → 误差量级 ∝ (1-t) → 0。另外可以每 K 步做一次"重去噪校正"：固定 s，跑 t: 当前→1，用精确 t 方向 velocity 重置 x。
风险 2：s→1 时的数值奇异性
d̂ = x̂₁ / (1-s)，s→1 时分母→0。
缓解：曲线在 τ→1 时 s→1 但不精确到达。实践中设 s_max = 0.97，最后一步直接用 x̂₁ 作为最终位移。
风险 3：训练分布未沿曲线密采样
训练在 (s,t) 平面均匀采样，曲线路径只走窄带。
缓解：训练覆盖全平面 → 曲线上每个点都在训练分布内。可选择性沿目标曲线做 biased sampling 加强。
风险 4：ε 在推理时是固定的
推理时 ε = randn 采一次，沿整条曲线不变。如果 ε 不好，整条曲线都受影响。
缓解：可以做多条曲线（不同 ε）取平均，类似 infer_avg_samples。或者用 zero-noise（geom_bridge）消除随机性——但那放弃扩散性。

7. 实现方案

7.1 推理端改动（训练不动）

def sample_disp_curve(self, cnn_feature, i_it_py, c_it_py, py_ind,
                      alpha=2.0, steps=20, batch=None):
    """2D FM 曲线推理路径"""
    N = i_it_py.size(0)
    h, w = cnn_feature.size(2), cnn_feature.size(3)
    contour_scale = self.compute_contour_scale(i_it_py)
    
    # 初始噪声
    x = torch.randn_like(i_it_py) * self._flow_noise_scale
    d_tau = 1.0 / steps
    
    for i in range(steps):
        tau = (i + 1) * d_tau
        t_val = tau ** (1.0 / alpha)
        s_val = tau ** alpha
        t_tensor = torch.full((N,), t_val, device=i_it_py.device)
        s_tensor = torch.full((N,), s_val, device=i_it_py.device)
        
        # 在当前 contour 上采 feature（DeepSnake 式）
        with torch.no_grad():
            xt_disp = self.denormalize_pred_disp(x, contour_scale)
            cur_contour = (i_it_py + xt_disp).detach()
            sampled_feat = snake_gcn_utils.get_gcn_feature(
                cnn_feature, cur_contour, py_ind, h, w)
            detail_feat = self.sample_detail_features(
                cnn_feature, cur_contour, py_ind, h, w,
                sampled_feat=sampled_feat, contour_scale=contour_scale)
        
        # t 方向速度
        v_t, _ = self.predict_velocity(
            cnn_feature, i_it_py, c_it_py, sampled_feat, detail_feat,
            py_ind, x, t_tensor * 1000, contour_scale=contour_scale.view(-1),
            s=s_tensor)
        
        # d̂ 估计
        x1_hat = x + (1 - t_val) * v_t
        d_hat = x1_hat / max(1 - s_val, 1e-4)
        
        # 速度合成
        dt_dtau = (1.0 / alpha) * tau ** (1.0 / alpha - 1)
        ds_dtau = alpha * tau ** (alpha - 1)
        dx = v_t * dt_dtau + (-t_val * d_hat) * ds_dtau
        
        x = x + dx * d_tau
    
    disp = self.denormalize_pred_disp(x, contour_scale)
    return self.clamp_pred_disp(disp, i_it_py)

8. 最终判断

理论可行性：成立。2D FM 面上任意连续曲线的 ODE 都 well-posed，模型在训练时覆盖全平面，曲线上每个点都在分布内。

下凸曲线的核心优势：结构性地将 s 方向误差积累放在 t≈1 的低误差区间（误差 ∝ (1-t)→0），同时去噪只做一次不重来，feature 沿真实轮廓连续重采。

主要不确定性：s 方向速度依赖 d̂ 的精度。如果模型在 t≈0.8 时 d̂ 已经够准（这需要实验验证），曲线就能优于阶梯。如果 d̂ 在 t<0.9 时误差仍然大，曲线可能不如阶梯（阶梯每步独立、无累积）。

建议：先在 s_cond + resample 训练好的 checkpoint 上跑 α=2 / steps=20 的推理实验。如果 20 步曲线 ≈ 100 步阶梯，就验证了效率优势。如果 20 步曲线 > 100 步阶梯，说明连续路径本身有质量优势。
