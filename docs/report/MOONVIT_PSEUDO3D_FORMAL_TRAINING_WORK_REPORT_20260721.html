00 / Executive conclusion

有界下游实验已结束；当前 GT-box 分割效果仍弱

本次完成的是使用冻结 MoonViT layer_18 离线 cache 的三切片伪3D下游监督训练，而不是 MoonViT 预训练。该 run 使用单张 GPU、batch size 1 和5,000次有放回 sampler draw；相对于14,384个名义 epoch positions 为34.76%，不能解释为唯一样本覆盖，更不能称为大规模训练。缓存、训练、监控、checkpoint、严格恢复和双口径验证均已落盘；当前没有活动训练进程。

02 / Final architecture

最终执行方案：三切片输入 + 冻结 MoonViT 特征注入

对同一病例的中心矢状位切片 x，输入三张真实灰度图 [x-1, x, x+1]；只使用中心层的 uint16 标签 mask 监督。模型不把它视为原生体素3D，而是在2D网络中用相邻层提供局部跨层上下文。

保留的关键设计

  • YOLOv8s P2/P3，25类，预训练 yolov8s.pt。
  • MoonViT-SO-400M 离线 cache，layer_18，输入448、patch14、每层1152通道。
  • concat(F_center, mean(F_prev, F_next))，得到2304通道的定位特征。
  • zero-init residual adapter 注入，不替换 YOLO detector feature。
  • rich-state sampling 保留，用于训练时轮廓状态/难度分布。

明确关闭的复杂分支

  • v4_1_use_detail_context=false
  • v4_1_final_head_type=standard
  • v4_10_use_dit_ffn_moe=false
  • 不启用 final-head MoE、不启用 DiT FFN-MoE。
  • 当前目标是验证 MoonViT伪3D主路径，不把 detail context / MoE 混入结论。

04 / Dataset and sampling

平衡采样解决空层占多数的问题，但不应误读运行时轮廓比例

原始 training manifest 有14,384张中心切片，其中5,838张含前景、8,546张为空层，原始前景比例约40.59%。如果不干预，batch size 1 的训练将较频繁遇到空层，轮廓与扩散监督会偏稀疏。

08 / Full validation

先看 GT-box：它是带条件的系统级分割测量

validation 全量包含6,247张切片，其中2,902张具有真实前景。GT-box 评估从真实 mask 派生每张切片的输入框，移除了 proposal 与 box-localization 误差；但 YOLO P2/P3 特征路径、adapter、Snake/Flow、训练预算和监督仍参与结果。因此它测量的是“给定正确框时的整个下游系统”，不能单独回答某一模块的因果贡献。

为什么 all-slice 不作主指标

GT-box all-slice Dice=0.596068、IoU=0.569833，但其中包含3,345张空层。空预测与空标注的一致会抬高均值，因此不应把这些数字当作前景分割能力。

可作与不可作的归因

GT-box 下 Dice=0.130474 表明给定正确框后的整体下游结果仍弱，也说明不能只把低分解释为找框失败；但该口径未冻结或移除 YOLO P2/P3 特征、adapter、Snake/Flow、预算和监督，不能把低分唯一归因给 Snake/Flow。

结果解释：该实验可复现，但只是一个有界的单卡下游训练结果；质量上，分割重叠仍弱。GT-box分数未证明 MoonViT改善，也没有证明三切片邻层上下文优于只复制中心层。下一步需要配对的2D baseline 与模块消融，而不是根据单一 run 作性能或模块因果结论。

10 / Decision and next experiment

结论：保留这条工程链路，下一步做严格 paired A/B

本次已验证

  • 全量 MoonViT cache 与三切片伪3D数据契约可用，MoonViT本体保持冻结。
  • 单卡 batch-1、有放回采样的5,000-step下游训练、健康监控和 checkpoint 恢复可用。
  • GT-box / predicted-box 双口径全量 validation 可以稳定落盘。
  • GT-box 可缩小 proposal/box-localization 的影响范围，但不产生模块级因果定位。

下一实验必须控制的变量

  1. 只改变 pseudo3d_input_mode：neighbors 对 center_repeat。
  2. 固定同一病例 split、seed、平衡采样序列、优化器、学习率和5,000 step预算。
  3. 同一步数 checkpoint 上先比较 GT-box foreground Dice / IoU，再单列 predicted-box 端到端结果。
  4. 至少多 seed，报告 paired difference，而不是比较两组独立最优 checkpoint。

推荐判断门槛：在相同预算、seed 与 sampling sequence 下，以 GT-box foreground-slice Dice / IoU 作为三切片对2D的主要比较，并配合 predicted-box 端到端结果与必要模块消融。只有出现多 seed 的稳定 paired 增益后，才考虑5切片或真正体素3D；不能仅因 loss 下降、all-slice 分数较高或单个有界 run 而作提升判断。
