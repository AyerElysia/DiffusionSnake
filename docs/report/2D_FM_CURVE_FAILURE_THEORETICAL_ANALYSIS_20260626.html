2D FM 曲线推理失败的理论根因分析

日期：2026-06-26  |  上下文：曲线推理 IoU=0.087（vs 阶梯 0.8177）的理论解释

一句话结论：当前训练模式不是真正的 2D FM，是"1D FM × 外部 rich-state 采样"。s 维度在训练时通过外部推进 init 实现（i_init = init + s·d），模型从未在同一个固定 init 上学过沿 s 方向连续演化。曲线推理违背这个隐含假设——它沿 s 移动但保持 init 不变——导致模型在严重 OOD 状态下评估。这不是 d̂ 数值误差，是结构性的训练-推理分布不匹配。

1. 严格推导：训练时 s 是怎么进入的

训练 forward 主路径（flow_matching_evolution.py:2274-2512）按顺序执行：

1.1 初始化 i_init_train_py

i_init_train_py = train_dict['i_it_py']   # 原始 init 轮廓（来自 octagon）
x1_raw         = i_gt_py - i_init_train_py   # 完整位移 d = GT - init

1.2 rich-state 采样推进 init（关键步骤）

frac ~ rich_state_sampling()                  # s ∈ [0, 1]
i_init_train_py = i_init_train_py + full_disp * frac   # ← 外部推进 init
x1_raw         = full_disp * (1.0 - frac)              # ← 残差位移 (1-s)·d
关键事实：训练时 i_init_train_py 被改成 已经前进了 s·d 的轮廓。模型在 advanced init 上做去噪，不是在原始 init 上。

1.3 采 feature 在 advanced init 上

feat_poly = i_init_train_py                       # = init + s·d（advanced contour）
sampled_feat = get_gcn_feature(cnn_feature, feat_poly, ...)

1.4 FM 训练目标

x1 = normalize(x1_raw) = (1-s)·d_normalized       # 残差（normalized）
x0 = ε (随机噪声)
x_t = (1-t)·ε + t·(1-s)·d_normalized
v_target = x1 - x0 = (1-s)·d_normalized - ε
模型输入: v_θ(x_t, s, t, feat_at_advanced_init)

2. 训练时模型实际看到了什么

在训练点 (s, t)，模型同时收到：

输入值含义
init（即 i_init_train_py）init + s·d已前进 s·d 的轮廓
feature在 init + s·d 上采advanced contour 周围的图像证据
x_t(1-t)·ε + t·(1-s)·d残差位移的带噪插值
sfracrefinement 进度
tU[0,1]去噪进度

模型学到的映射：

v_θ(x_t, s, t, feat(init+s·d)) ≈ (1-s)·d - ε

这个映射的隐含条件是：模型看到的 init 已经前进了 s·d。

3. 曲线推理时模型实际看到了什么

曲线推理（sample_disp_curve）沿 (s(τ), t(τ)) 走。在点 (s, t)：

输入曲线推理传入训练期望匹配？
init（i_it_py）init（原始，固定不变）init + s·d不匹配
feature在 init + denorm(x_t) 上采在 init + s·d 上采不匹配
x_t(1-t)·ε + t·(1-s)·d̂（积分累积值）(1-t)·ε + t·(1-s)·d近似（含误差）
s当前 τ 对应的 s_val当前 s匹配
t当前 τ 对应的 t_val当前 t匹配
根本不匹配：曲线推理传入的 i_it_py 始终是原始 init，但训练时模型见到的 init 是 init + s·d。

举例：s=0.5, t=1 时
- 训练：模型看到 init=init+0.5d，x=0.5d，目标 v=0.5d-ε
- 曲线推理：模型看到 init=init，x≈0.5d̂，目标 v≈0.5d̂-ε
- 模型在原始 init 上看到 x=0.5d 的位移——这等价于 s=0（还没前进）但 x 已经是 0.5d，是训练分布外的输入。

4. 为什么阶梯推理却 work

阶梯推理（sample_disp_iterative）每步：

current_contour = i_it_py.clone()           # 初始 = 原始 init
for each outer step:
    feat = resample(current_contour)         # 在当前 contour 上采
    disp = sample_disp_from_sampled_feat(...)  # 跑完整 t:0→1 ODE
    current_contour = current_contour + frac * disp   # ← 推进 init！
    cumulative_s += (1-cumulative_s) * frac   # s 推进

每个 outer step 结束后 current_contour 被显式推进——下一个 step 的 init 是 advanced contour，feature 在 advanced contour 上采。这正是训练时模型见到的分布！

阶梯推理 work 的原因：它显式地推进 current_contour，让每个 outer step 的 init 和 feature 都匹配训练分布。曲线推理没有推进 init，只是在固定 init 上让 x 变化——和训练完全不一致。

5. 这就是"不是真二维"

真正的 2D FM 应该是：

状态: X(s, t) ∈ 物理坐标空间
∂X/∂t = v_θ(X, s, t)           # t 方向：去噪（模型学）
∂X/∂s = u_θ(X, s, t)           # s 方向：refine（模型也学）
推理：沿任意曲线 (s(τ), t(τ)) 积分 dX/dτ

当前的"伪 2D"：

训练: s 是外部参数，通过推进 init 实现（不是模型的 s 方向速度）
     只在 t 方向学 FM（1D FM × rich-state 参数化）
推理: 沿任意 s 方向走时，必须外部推进 init——否则分布外
     这只能做"分段 1D FM"（阶梯），不能做连续 2D 曲线

s 维度从未被模型内部化：它只是一个告知模型的"进度标签"，实际 init 推进由外部代码完成。模型从来没有学过"在同一个 init 上，s 增加 → 残差自然减少"的连续演化。

6. 严格证明：曲线推理为何必然失败

令 M(s, t, init_adv, x) 表示模型在点 (s,t)、init_adv、输入 x 下的预测。训练目标：

M(s, t, init+s·d, (1-t)ε+t(1-s)d) → (1-s)d - ε   (训练分布)

曲线推理传入：

M(s, t, init, x_curve(τ))   where x_curve evolves via Euler

当 s > 0 时，init ≠ init + s·d。模型在从未见过的输入组合下评估。泛化保证只覆盖训练分布的支持集——(init, s>0, x_t=正确的残差) 不在支持集内（因为训练时 init 一旦不是原始 init，就是 init+s·d）。

结论：不存在一致的推理时欧拉方案能让曲线推理从当前训练的模型中正确工作，除非每个曲线点都显式推进 init（等价于阶梯）。这是结构性的不匹配，不是数值噪声。

7. 三种可能的解决方向

7.1 方向 A：改训练范式为真 2D（最激进）

训练时不再推进 init（i_init_train = 原始，不 advance）
让 x_t = (1-t)ε + t·(1-s)·d   # 在固定 init 上
模型在原始 init 上学习 s 方向连续演化
特征在固定 init 上采（固定特征）
→ 模型内部化 s 维度
→ 推理时可以在固定 init 上走任意曲线

成本：放弃 rich-state 训练带来的数据增广（init 在不同 s 下是不同轮廓），训练分布变窄。但可能让曲线推理成立。

7.2 方向 B：曲线推理时也推进 init（妥协方案）

曲线推理也显式推进 init:
    init_adv = init + cumulative_s · d̂
    feat = resample(init_adv)
    但这等价于阶梯 + 特征重采——和现有 iterative 推理一样
→ 曲线推理没有独立意义

结论：这个方向让曲线推理退化为阶梯，不增加新能力。

7.3 方向 C：让模型学 s 方向速度（真 2D FM）

状态: X = init + x 是 contour 坐标
训练目标新增: u_θ(X, s, t) ≈ ∂X/∂s = -t·d    # s 方向速度也学
推理曲线: dX/dτ = v_θ·dt/dτ + u_θ·ds/dτ
→ 不需要 d̂（因为 u_θ 自己估计了 s 方向速度）
→ 训练是真正的 2D PDE 学习

成本：需要改训练 loss 增加 s 方向项。但训练时 s 推进 init 的事实仍然存在——除非同时改为方向 A。

8. 我（Claude）的看法

当前实验已经验证了一个非常重要的事实：显式 s-conditioning 加值显著。1232_final 上 s_cond 200ep 阶梯 0.818 vs pretrain 3000ep 0.746，+7.1 个点。这个收益来自模型"知道自己在 refinement 的哪个阶段"，能各自策。

但这个收益不需要真 2D FM——它只需要 s 作为条件标签，阶梯推理就能 extract 这个收益。曲线推理只是"如果真 2D 成立时"的额外红利。

如果要追求真 2D 曲线推理，最干净的方向是 方向 A（改训练范式）：让 init 固定、s 是内部维度。但这放弃了 rich-state 的 init 增广，可能掉点。需要实验权衡。
