01 / Definition

什么是伪3D，它不是什么

伪3D在不引入完整3D网络的前提下，把中心层两侧的局部体数据上下文映射到普通三通道2D输入。监督目标仍严格属于中心层，因此输出与单张矢状位标签一一对应。

2D baseline

单层2D / center_repeat

输入是 [Ix, Ix, Ix]。三通道接口不变，但没有邻层信息，是与 neighbors 配对的直接对照。

This method

三切片伪3D / neighbors

输入是 [Ix-1, Ix, Ix+1]。2D网络可在通道维读取局部 X 方向变化，只监督 Mx。

Not implemented here

真正3D

真正3D模型以体块为输入，使用3D卷积、体素注意力或体级算子，并输出体素级结果。本方案既不保留完整体积，也没有3D空间核。

“伪3D”不等于把灰度图染成 RGB。模型输入的三个通道分别是三张真实相邻切片；本报告中的 pseudo-RGB 只是把它们映射到 R/G/B 以观察层间差异，不能作为医学颜色解释。

如果改成体素3D，哪些能复用，哪些必须重做

模块体素3D改造判断
数据与坐标回到 NIfTI，统一 orientation、spacing、强度窗和体块采样；标签改为体素级25类 mask必须新建3D数据管线，但现有病例 split、类别定义和坐标审计可复用
特征编码器以3D CNN、3D Swin/UNETR 或2D MoonViT逐层编码后加跨层聚合器替代当前三通道 YOLO核心 backbone 需要更换；MoonViT可作为2D初始化或切片特征教师，不能直接当原生3D编码器
检测与轮廓2D box 与128点平面轮廓要改为3D proposal + 体素 mask，或3D mesh / surface point 表示如果目标是体素分割，这部分属于大改，现有 Snake 输出头不能原样复用
训练框架loss logging、checkpoint、optimizer、病例划分和 GT/predicted 双口径思想仍保留工程骨架可复用，模型与数据契约需要重构

结论：改成真正的体素3D不是给当前模型再加一个开关。若目标是3D体素分割，数据 loader、backbone、检测/输出表示和 evaluator 都要更换，属于模型主干层面的“大换血”；但数据 split、MoonViT预训练知识、训练基础设施和评估纪律不必推倒重来。更稳妥的顺序是先证明三切片伪3D稳定增益，再做小体块3D基线，而不是直接扩成整卷模型。

04 / Core algorithm

核心算法、边界策略与病例安全约束

Dataset 先按 case_id 分组，再按整数 slice_idx 排序。组内重复序号会被拒绝；对非边界层取样时，若 x-1 或 x+1 缺失，会立即报错。邻层查找只在当前病例的字典中完成，因此不会借用另一病例的末层或首层。

prev(x) = Ix if x = xfirst, else Ix-1
next(x) = Ix if x = xlast, else Ix+1
Xneighbors(x) = Stackchannel[prev(x), Ix, next(x)] / 255
Xcenter_repeat(x) = Stackchannel[Ix, Ix, Ix] / 255
supervision(x) = Mx,   Mx ∈ {0, 1, ..., 25}H×W
Manifest rows读取目标 split
→
Group by case绝不跨 case_id
→
Sort & validate按 slice_idx；拒绝重复/内部缺层
→
Read 3 imagesuint8；shape 必须一致
→
Read center mask仅 Mx；uint16

首尾复制

病例首层输入索引为 [first, first, first+1]；末层为 [last-1, last, last]。这样维持三通道形状且不制造跨病例邻接。

内部连续性

内部层必须能在同一 case_id 中精确找到 x-1 和 x+1。缺失不是静默复制，而是数据一致性错误。

安全不变量：三个输入通道来自同一病例；标签只来自中心层；图像与 mask shape 一致；图像 dtype 为 uint8；mask dtype 为 uint16；标签值只允许 0..25。

05 / Supervision mapping

从中心 mask 到 Snake / YOLO 监督

对中心 mask 的每个非零标签单独生成二值图，并调用 cv2.findContours(..., cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_NONE)。RETR_EXTERNAL 只提取该类别的外部轮廓；同类存在多个外部连通组件时，每个有效组件分别成为一个实例。

语义层类别范围映射用途
uint16 mask0..250 背景，1..25 前景类别中心层像素标签来源
Snake / heatmap1..25保持 mask 的 1-based labelct_hm 共26通道，背景索引保留
YOLO0..24yolo_cls = label - 125类 box 检测监督

每个外部轮廓进一步生成检测框、中心 heatmap、宽高、极值点、octagon/Snake 初始化多边形和128点演化目标。空中心 mask 返回合法的零实例张量，仍可被 collator 组成 batch；此时没有轮廓级 Flow Matching 监督，日志中的 diff_loss=0。

06 / Preprocessing

共享 affine、尺寸与 MoonViT 预处理

YOLO/Snake 输入仍把三张邻层按 [x-1,x,x+1] 堆叠，再通过同一个 affine 变换进入 512×512 坐标；中心 mask 的多边形监督使用同一变换。真实 DataLoader 已验证 batch 为 (2, 3, 512, 512)，真实 MoonViT 融合张量为 (2, 2304, 32, 29)。

关键区别：YOLO 的输入是三张邻层组成的伪3D三通道；MoonViT 不是把这三张图直接当 RGB，而是对每张切片单独做灰度到 RGB 的复制并提取特征，之后才进行中心/邻层特征融合。

用于可视化的 orig_img 是 affine 后中心层重复到三通道，不是 pseudo-RGB，避免把层间通道差异误画成模型输出底图。

07 / Symmetric initialization

YOLO stem 三通道对称初始化

加载官方 YOLO 预训练权重后，对第一层 stem 卷积做通道对称化。对每个输出通道与空间核位置，先求原 RGB 三个输入通道权重的平均，再把平均核复制到三个伪3D通道。

W̄o,u,v = (Wo,0,u,v + Wo,1,u,v + Wo,2,u,v) / 3
W′o,0,u,v = W′o,1,u,v = W′o,2,u,v = W̄o,u,v
For [I, I, I]:   Σc W′o,c * I = Σc Wo,c * I

保持预训练响应

当输入是 center_repeat=[I,I,I] 时，对称化前后的 stem 卷积响应相同，不破坏预训练网络对重复灰度输入的起始行为。

不给邻层先验偏置

三个通道以完全相同的核开始训练，避免把自然图像 RGB 通道差异错误地解释为 previous / center / next 的重要性差异。

对应开关为 pseudo3d_symmetric_stem_init=true；实现位于 Network.make_symmetric_stem_weight，并有响应保持单元测试。

GT-box conditional 与 predicted-box end-to-end 应同时报告。前者缩小了 proposal / box-localization 误差的影响范围，后者保留完整检测路径；两者不是可互换的“两个精度数字”，GT-box 也不能被表述为只测量轮廓模块。

评估架构必须严格一致：tools/eval_sagittal_2d_fixed.py 默认加载当前 MoonViT 配置，并要求 checkpoint 为 missing=0, unexpected=0。若误用旧 detail+MoE 配置或不匹配的 checkpoint，评估会直接失败，不再带随机初始化模块继续产出无效指标。

12 / Controlled comparison

neighbors vs center_repeat：现有证据与严谨对照

已有 CPU 短程 smoke 对两条输入链各运行100 step，并固定为50个前景样本与50个空样本。它验证两种输入模式都能完成 forward / backward 与参数更新，但不构成 accuracy 对照。

推荐的正式 A/B 协议

  1. 只改变 pseudo3d_input_mode；其他 YAML、预训练权重、stem 对称初始化、优化器和增强完全一致。
  2. 使用同一病例 split、同一 seed、同一前景/空层采样序列；两组均采用 balanced sampling。
  3. 给予相同的 optimizer step 预算、学习率日程、batch size 和 checkpoint 频率，先完成 5k–10k step。
  4. 在相同步数 checkpoint 上分别运行 GT-box oracle 与 predicted-box end-to-end；主指标为 foreground-slice Dice / IoU，同时报告 class mean 和 n_pred。
  5. 至少运行多个 seed，报告 paired difference 与波动范围；不得用每组最优 checkpoint 做非配对比较。

13 / Limitations and next steps

局限与下一步

当前局限

  • 已结束的是单卡 batch-1、5,000-draw的有界下游训练，不是 MoonViT 预训练或大规模训练；有放回抽样不能单独证明收敛、泛化或数据覆盖。
  • 原始 training manifest 中8,546 / 14,384为空中心层；balanced sampler 将采样目标固定为前景/空层各50%，前5,000 draws 重建为2,532 / 2,468，但 transform 后实际轮廓监督为2,170 / 5,000步。
  • GT-box 条件系统指标 Dice=0.130474 仍较弱；它排除了 proposal / box-localization 误差，但不能唯一归因任一剩余模块。
  • 训练中出现一次约10.5分钟 transient stall，已恢复并正常完成；后续长训仍需保留 heartbeat 与 checkpoint 监控。
  • 暂无同预算、同 seed 的 neighbors / center_repeat accuracy 对照，也没有针对 YOLO P2/P3、adapter、Snake/Flow 的模块消融，不能宣称 MoonViT 提升。

下一步顺序

  1. 以当前 GT-box 条件系统指标为基线，先做同预算、同 seed、同 sampling sequence 的 center_repeat 对照。
  2. 在相同步数 checkpoint 上同时报告 GT-box 条件指标和 predicted-box 端到端指标。
  3. 为 YOLO P2/P3特征、MoonViT adapter与 Snake/Flow 分别设计消融，避免把 GT-box 分数当作模块级诊断。
  4. 仅在多 seed 的三切片相对2D baseline 存在稳定 paired 增益后，再测试5切片或真正体素3D模型。

决策门槛应建立在 foreground-slice accuracy、类别覆盖、检测召回和多 seed 稳定性上，而不是 all-slice Dice 或短程训练 loss。
