# 毛刺问题分析工具

## 概述

这套工具用于深度分析DiffusionSnake预测轮廓中的毛刺现象，特别关注点序是否是导致毛刺的原因。

## 文件说明

### 1. `analyze_burr_scatter.py`
主分析脚本，提供：
- **散点图可视化**：不按点序连线，直接显示点的分布
- **曲率热力图**：用颜色标识每个点的曲率大小
- **统计指标**：量化毛刺现象的多个维度
- **后处理对比**：对比平滑前后的效果
- **点序分析**：自动调用点序分析模块

### 2. `analyze_point_order.py`
点序专项分析模块，提供：
- **点序跳跃检测**：识别相邻点距离异常大的位置
- **点编号可视化**：显示每个点的索引和连接顺序
- **最近邻重排**：尝试用最近邻算法重新排列点序
- **改进效果评估**：量化重排后的改进程度

### 3. `edge_smoothing.py`
边缘感知平滑模块（已有），用于后处理对比。

### 4. `run_burr_analysis.sh`
批量运行脚本，分析多个样本。

2. **`burr_idx{N}_original_order.png`**
   - 原始点序可视化

   - 用彩虹色显示点的顺序

5. **`burr_idx{N}_metrics.json`**

   - 包含原始预测、平滑后、点序分析三部分数据

## 统计指标说明

### 毛刺相关指标

1. **点间距离统计**
   - `dist_mean`: 平均点间距
   - `dist_std`: 标准差
   - `dist_cv`: 变异系数（std/mean），越大说明点分布越不均匀
   - `dist_max`: 最大点间距（可能是跳跃）

2. **曲率统计**
   - `curv_mean`: 平均曲率
   - `curv_max`: 最大曲率（尖锐转角）
   - `curv_outliers`: 异常尖锐点数量（超过95分位数的2倍）

3. **转角统计**
   - `sharp_angles`: 大于120度的尖锐转角数量

4. **高频振荡**
   - `deviation_mean`: 点到前后连线的平均偏离
   - `high_freq_points`: 高频振荡点数量（偏离超过均值+2倍标准差）

### 点序分析指标

1. **原始点序**
   - `num_jumps`: 检测到的跳跃数量
   - `jump_ratio`: 跳跃比例（跳跃数/总点数）

2. **重排后**
   - `jump_reduction`: 跳跃减少数量
   - `max_dist_reduction`: 最大距离减少量
   - `std_reduction`: 标准差减少量

## 分析思路

### 判断毛刺是否由点序导致

1. **查看散点图**
   - 如果散点图看起来很平滑，但连线图有毛刺 → 很可能是点序问题
   - 如果散点图本身就很乱 → 可能是预测质量问题

2. **查看点序跳跃**
   - 如果检测到大量跳跃（>10%的点） → 点序有问题
   - 查看跳跃位置是否对应毛刺位置

3. **查看重排效果**
   - 如果重排后跳跃大幅减少 → 说明原始点序确实有问题
   - 对比重排前后的连线图，看毛刺是否减少

4. **查看曲率热力图**
   - 红色区域（高曲率）对应尖锐转角
   - 如果高曲率点集中在跳跃位置 → 点序导致的假毛刺
   - 如果高曲率点分散且对应真实边缘 → 可能是真实的复杂形状

### 可能的结论

**情况A：点序导致的毛刺**
- 散点图平滑，连线图有毛刺
- 大量点序跳跃
- 重排后效果明显改善
- **解决方案**：修改训练/推理时的点序生成逻辑

**情况B：预测质量问题**
- 散点图本身就很乱
- 点序跳跃少
- 重排后改善不明显
- **解决方案**：改进模型训练，增强平滑约束

**情况C：混合问题**
- 既有点序跳跃，散点图也有噪声
- **解决方案**：同时优化点序和模型训练

## 下一步建议

根据分析结果，可以：

1. **如果是点序问题**
   - 检查 `lib/utils/snake/snake_gcn_utils.py` 中的 `uniform_upsample` 逻辑
   - 检查初始化八边形的点序是否正确
   - 考虑在推理时使用最近邻重排作为后处理

2. **如果是预测质量问题**
   - 增加训练时的平滑损失
   - 调整扩散步数
   - 使用边缘感知平滑作为后处理

3. **设计新的实验**
   - 在训练时强制点序一致性
   - 使用重排后的轮廓作为伪标签重新训练
   - 设计点序感知的损失函数

## 注意事项

1. **模型权重**：确保V3.4模型的权重存在于 `data/outputs/btcv_diffusion_dit_v3_4/checkpoints/latest.pt`

2. **环境**：必须在 `snake1` conda环境中运行

3. **GPU**：会自动使用可用的GPU，如果没有GPU会回退到CPU（较慢）

4. **数据集**：使用配置文件中指定的测试集路径

## 示例输出解读

```
点序跳跃检测:
    总点数: 128
    平均点间距: 3.45
    标准差: 1.23
    最大点间距: 15.67
    检测到跳跃: 8 处
    跳跃位置: [12, 34, 56, 78, 90, 102, 115, 120]
```

这说明：
- 有8个位置的点间距异常大（超过均值+3倍标准差）
- 最大跳跃距离是15.67像素，而平均只有3.45像素
- 这些跳跃很可能导致连线时出现毛刺
