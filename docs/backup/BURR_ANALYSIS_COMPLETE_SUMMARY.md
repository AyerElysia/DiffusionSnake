**问题：**

**结果：**
- 小轮廓点太密集，对噪声敏感
- 微小的预测误差导致巨大的曲率变化

## 原因分析

### 原因1：信噪比问题

```
小轮廓（点密度0.59）：
- 相邻点距离：~0.6像素
- 预测噪声：~0.5像素
- 信噪比 = 0.6 / 0.5 = 1.2（很低！）

大轮廓（点密度2.93）：
- 相邻点距离：~3.0像素
- 预测噪声：~0.5像素
- 信噪比 = 3.0 / 0.5 = 6.0（较高）
```

### 原因2：曲率计算的数值不稳定性

曲率 = 二阶差分 = (p[i+1] - p[i]) - (p[i] - p[i-1])

当相邻点距离很小时（小轮廓），二阶差分对噪声极其敏感。

### 原因3：扩散模型的分辨率限制

- 特征图下采样4倍
- 小轮廓在特征图上只有几个像素
- 特征图上1像素误差 = 原图4像素
- 对小轮廓来说，这个误差占比很大

---

## 解决方案

### 推荐方案：自适应点数 ⭐⭐⭐⭐⭐

**核心思路：** 根据轮廓周长动态调整点数，保持一致的点密度

**实现：**
```python
def adaptive_num_points(perimeter):
    target_density = 2.5  # 目标点密度（像素/点）
    num_points = int(perimeter / target_density)
    num_points = max(32, min(num_points, 256))
    return num_points

# 示例：
# 轮廓1（周长75.8）：75.8 / 2.5 = 30 → 32点
# 轮廓4（周长374.8）：374.8 / 2.5 = 150 → 152点
```

**预期效果：**

| 轮廓 | 当前点数 | 建议点数 | 当前曲率 | 预期曲率 | 改善 |
|------|---------|---------|---------|---------|------|
| 1 | 128 | 32 | 36.16 | 15-20 | 40-50% |
| 5 | 128 | 64 | 25.52 | 12-15 | 40-50% |
| 2 | 128 | 72 | 22.64 | 10-12 | 45-55% |
| 3 | 128 | 120 | 11.76 | 8-10 | 20-30% |
