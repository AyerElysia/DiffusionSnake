## 为什么小轮廓更容易毛刺？

### 原因1：点密度过高导致的敏感性

**问题：** 所有轮廓都使用固定的128个点

- **小轮廓**（如轮廓1，周长75.8）：
  - 点密度 = 75.8 / 128 = **0.59 像素/点**
  - 相邻点距离平均只有0.59像素
  - **微小的预测误差（0.5像素）就会导致巨大的曲率变化**

- **大轮廓**（如轮廓4，周长374.8）：
  - 点密度 = 374.8 / 128 = **2.93 像素/点**
  - 相邻点距离平均2.93像素
  - 同样0.5像素的误差，曲率变化小得多

### 原因2：信噪比问题

**小轮廓的信噪比更低：**

```
信噪比 = 真实信号 / 噪声

小轮廓：
- 真实信号：相邻点距离 ~0.6像素
- 预测噪声：~0.5像素
- 信噪比 = 0.6 / 0.5 = 1.2（很低！）

大轮廓：
- 真实信号：相邻点距离 ~3.0像素
- 预测噪声：~0.5像素
- 信噪比 = 3.0 / 0.5 = 6.0（较高）
```

**结论：** 小轮廓的预测噪声占比更大，更容易产生毛刺。

### 原因3：扩散模型的分辨率限制

扩散模型在特征图上操作，特征图的分辨率有限：

- 假设特征图下采样4倍（down_ratio=4）
- 小轮廓在特征图上可能只有几个像素
- **特征图上的1个像素误差，在原图上就是4个像素**
- 对小轮廓来说，这个误差占比很大

### 原因4：曲率计算的数值不稳定性

曲率计算使用二阶差分：

```python
d2 = (p[i+1] - p[i]) - (p[i] - p[i-1])
curvature = ||d2||
```

当相邻点距离很小时（小轮廓），二阶差分对噪声非常敏感：

- 小轮廓：d1 ~0.6像素，噪声0.5像素 → d2的噪声被放大
- 大轮廓：d1 ~3.0像素，噪声0.5像素 → d2相对稳定

## 理论分析

### 点密度的最优范围

根据数据，我们可以推断：

| 点密度 | 曲率范围 | 效果 |
|--------|---------|------|
| < 1.0 | 20-36 | 过密，严重毛刺 |
| 1.0-2.0 | 10-25 | 偏密，中等毛刺 |
| 2.0-3.0 | 4-12 | 适中，轻微毛刺 |
| > 3.0 | ? | 可能过疏，无法表示细节 |

**最优点密度：** 约2.0-3.0像素/点

### 为什么固定128点不合理？

当前所有轮廓都使用128个点，这导致：

1. **小轮廓过采样**：点太密集，噪声敏感
2. **大轮廓可能欠采样**：点可能不够表示复杂形状（虽然当前数据中大轮廓效果好）

**更合理的方案：** 根据轮廓周长自适应调整点数

## 验证实验设计

### 实验目标

验证假设：**调整点数可以改善小轮廓的毛刺问题**

### 实验方案

#### 方案A：减少小轮廓的点数 ⭐⭐⭐⭐⭐

**假设：** 小轮廓使用更少的点，可以降低点密度，减少毛刺

**实验设计：**

1. **对不同大小的轮廓使用不同的点数**

```python
def adaptive_num_points(perimeter):
    """根据周长自适应确定点数"""
    target_density = 2.5  # 目标点密度（像素/点）
    num_points = int(perimeter / target_density)
    
    # 限制在合理范围
    num_points = max(32, min(num_points, 256))
    
    # 确保是4的倍数（方便处理）
    num_points = (num_points // 4) * 4
    
    return num_points

# 示例：
# 轮廓1（周长75.8）：75.8 / 2.5 = 30 → 32点
# 轮廓4（周长374.8）：374.8 / 2.5 = 150 → 152点
```

2. **修改数据准备流程**

在 `lib/datasets/` 中修改轮廓采样逻辑：

```python
# 当前：固定128点
poly_128 = uniform_upsample(poly_init, 128)

# 改为：自适应点数

num_points = adaptive_num_points(perimeter)
poly_adaptive = uniform_upsample(poly_init, num_points)
```

3. **修改模型以支持可变点数**

- 当前模型假设所有轮廓都是128点
- 需要修改为支持batch中不同轮廓有不同点数

## 替代方案

如果自适应点数实现困难，可以考虑：

### 方案D：尺度归一化训练 ⭐⭐⭐⭐

**思路：** 在训练时将所有轮廓归一化到相同的尺度

```python
def normalize_contour(contour):
    """将轮廓归一化到固定尺度"""
    perimeter = compute_perimeter(contour)
    scale = 200 / perimeter  # 归一化到周长200
    contour_normalized = contour * scale
    return contour_normalized, scale

# 训练时
contour_norm, scale = normalize_contour(contour)
pred_norm = model(image, contour_norm)
pred = pred_norm / scale  # 反归一化
```

**优点：**
- 所有轮廓在相同的尺度上训练
- 模型看到的点密度一致
- 不需要修改模型架构

**缺点：**
- 需要修改训练流程
- 可能影响绝对位置的学习

---

### 方案E：多尺度训练 ⭐⭐⭐

**思路：** 对小轮廓进行上采样，对大轮廓进行下采样

```python
def multi_scale_augmentation(contour):
    """多尺度数据增强"""
    perimeter = compute_perimeter(contour)
    
    if perimeter < 150:  # 小轮廓
        # 放大2倍
        contour = contour * 2
    elif perimeter > 300:  # 大轮廓
        # 缩小到0.5倍
        contour = contour * 0.5
    
    return contour
```

**优点：**
- 简单易实现
- 可以作为数据增强

**缺点：**
- 改变了轮廓的绝对大小
- 可能影响其他任务
