# 毛边问题深度分析 — V3.0 vs V3.3 (2026-04-16)

## 1. 现象总结

### V3.0 (epoch 10000, diff_loss=0.000103)
- ✅ 整体轮廓形状正确，大部分器官边界能对齐
- ❌ **所有轮廓都有明显的锯齿/毛边**，像锯齿波一样抖动
- 小器官（肾上腺、胆囊）上毛边尤其明显

### V3.3a (epoch 9000, diff_loss=0.000086)
- ❌ **比V3.0更差**，大器官轮廓出现严重的高频抖动
- 尤其是肝脏和脾脏的轮廓，出现蓝红交替的密集锯齿
- 尽管训练loss更低，视觉效果明显退步

### V3.3b (epoch 7600, total_loss=13.6)
- ❌ **灾难性失败**，轮廓完全爆炸，红线覆盖整张图
- smooth_loss=65, curv_loss=262 远大于 diff_loss=0.013
- 两个loss目标互相冲突，训练崩溃

## 2. 毛边的根本原因分析

### 2.1 扩散模型的固有问题：逐点独立预测

**这是最核心的原因。** 当前架构预测 128 个轮廓点的位移，每个点的位移由扩散
采样过程中的噪声去除决定。关键问题：

1. **DDIM采样起始于纯高斯噪声 `x_T ~ N(0,I)`**
   - 每个点的初始噪声是独立采样的
   - 相邻点之间没有任何关联性

2. **去噪过程不保证相邻点一致性**
   - 虽然 DiTDenoiserV3 有 Self-Attention（全局关系）
   - 但 Self-Attention 学到的是"预测正确的噪声"，不是"预测平滑的噪声"
   - 当 loss 足够低时，模型能预测正确的均值方向
   - 但无法消除采样过程中引入的逐点随机性

3. **数学角度：DDIM 采样的残余方差**
   ```
   x_{t-1} = sqrt(α_{t-1}) * x0_pred + sqrt(1-α_{t-1}) * direction
   ```
   即使 x0_pred 完美，direction 项中残留的高频分量仍然会导致毛边。
   50步 DDIM 不足以完全消除高频噪声残留。

### 2.2 Displacement 空间的本质问题

**位移场是二维向量场，自然存在高频分量。**

- 器官边界的GT位移本身可以是光滑的（初始轮廓到GT轮廓的平滑映射）
- 但归一化后的位移 ∈ [-1, 1]，扩散过程在这个空间添加噪声
- 去噪后每个点独立到达"正确附近"，但点与点之间没有强制连续性
- 就像128个人各自GPS导航到目的地，每个人都到了附近，但站位并不整齐

### 2.3 为什么V3.0在10000epoch后仍有毛边？

**因为毛边不是训练不足的问题，而是推理机制的问题。**

| 指标 | V3.0 | 说明 |
|------|------|------|
| diff_loss | 0.000103 | 极低，训练已完全收敛 |
| 噪声预测精度 | 极高 | 模型完美学会了噪声 |
| 推理毛边 | 严重 | DDIM采样固有高频残留 |

训练loss衡量的是"预测噪声的MSE"，不是"输出轮廓的平滑度"。
**即使噪声预测完美，DDIM采样的随机初始化和有限步数仍然导致毛边。**

## 3. V3.3 为什么失败？

### 3.1 V3.3a（CircularConv1d）为什么更差？

CircularConv1d 的设计意图是在特征空间做平滑：
```python
# 在 FinalLayer 之前，对 feature 做 1D 环形卷积
x = self.circular_conv(x)  # 残差权重 0.1
```

**失败原因：**

1. **作用点错误**：CircularConv 在 **feature 空间** 操作，不在 **displacement 空间**
   - Feature 空间的"平滑"≠ Output 空间的"平滑"
   - 256维的 feature 被卷积混合后，经过 FinalLayer 线性投影到 2维
   - 线性投影可以把平滑的 feature 变成不平滑的 displacement

2. **残差权重太小**：0.1 的残差意味着只有 10% 的修正
   - 如果 feature 本身已经"学好了"高频位移，0.1 的平滑修正不够
   - 相反，额外的 Conv1d 参数增加了模型容量，可能学到更精细的高频

3. **训练目标仍然是 MSE(eps_pred, eps)**
   - CircularConv 被梯度优化来最小化噪声预测误差
   - 优化器完全可以让 Conv1d 学到 identity 或者放大高频的权重
   - 没有任何约束强制 Conv1d 做"低通滤波"

### 3.2 V3.3b（smooth_loss + curv_loss）为什么灾难性爆炸？

```
epoch    0: smooth=17714776  curv=70332472   diff=1.01
epoch  100: smooth= 4977095  curv=19759930   diff=0.66
epoch 5000: smooth=      45  curv=      182  diff=0.03
epoch 7000: smooth=    1652  curv=     6607  diff=0.009
epoch 8000: smooth=      65  curv=      263  diff=0.013
```

**失败原因：两个 loss 的梯度方向互相矛盾。**

1. **smooth_loss 通过 `_predict_x0_from_eps` 反向传播**
   ```python
   x0_pred = (x_t - sqrt(1-α_bar) * eps_pred) / sqrt(α_bar)
   ```
   - 当 t 很大时（接近纯噪声），`sqrt(α_bar)` 接近 0
   - 除以接近零的值会导致 **x0_pred 的梯度被放大几千倍**
   - smooth_loss 的梯度在大 t 时极度不稳定

2. **目标冲突**
   - diff_loss 要求：`eps_pred ≈ 真实噪声 eps`（随机高斯，天然高频）
   - smooth_loss 要求：`x0_pred` 对应的轮廓平滑（低频）
   - 但 x0_pred 是从 eps_pred 推导出来的！
   - 要求噪声预测准确 AND 预测结果平滑 → 数学上矛盾

3. **数值不稳定**
   - 初始 smooth_loss=17714776，即使权重只有 0.05
   - 0.05 × 17714776 = 885,739 >> diff_loss=1.01
   - smooth_loss 完全支配了训练，扩散损失被忽略
   - 模型学到的不是"去噪"而是"让输出看起来平滑"

## 4. 关键洞察

### 毛边问题的本质是：**输出空间缺乏结构性约束**

扩散模型在 (N, 128, 2) 的位移空间工作，把 128 个 2D 点当作 **独立的**
256 维向量来去噪。它不"知道"这些点构成一条闭合曲线。

解决方案必须从以下角度之一入手：
1. **改变表示空间**：不预测逐点位移，而预测天然平滑的表示（如傅里叶系数）
2. **后处理**：推理后对预测轮廓做低通滤波
3. **约束扩散过程**：让噪声和去噪都在低频子空间进行
